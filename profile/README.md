# Hyland Labs

Unofficial experiments from Hyland team members.

Projects in this organization are experimental and are not Hyland products. Hyland does not support them, maintain them on a schedule, or guarantee they work. Use them at your own risk. A project can change, stop being updated, or be removed without notice.

## What You'll Find Here

- Proofs of concept, demos, and sample code
- Tools and extensions built on top of Hyland open source projects, such as OpenArch
- Ideas we're testing in the open before deciding whether to invest in them

## What You Won't Find Here

Supported Hyland open source projects live in the [Hyland](https://github.com/Hyland) organization. If a Labs project becomes supported, it moves there.

## Using a Project

- Check each repository's LICENSE file. Licenses can differ between projects
- Read the project's README for its status and any known limits
- Don't use these projects in production unless you've reviewed and tested them yourself

## Contributing

This organization is not accepting outside contributions yet. The process is still being finalized, and this section will be updated when that changes.

Contributions to a project here require signing the Hyland Contributor License Agreement. See [CONTRIBUTING.md](https://github.com/HylandLabs/.github/blob/main/CONTRIBUTING.md), and check the project's own README or CONTRIBUTING file for anything specific to it.

## Reporting a Security Issue

Please don't open a public issue for security problems. Report them privately to SECURITY-CONTACT-TBD. See [SECURITY.md](https://github.com/HylandLabs/.github/blob/main/SECURITY.md) for what to include and what to expect.
