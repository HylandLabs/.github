# Contributing

Thanks for your interest in a Hyland Labs project.

## Current Status

This organization is not accepting contributions from outside Hyland yet. The process is still being finalized. Issues and discussions are the best way to reach a project's maintainers in the meantime, and this page will be updated when contributions open.

## Contributor License Agreement

When contributions open, every contributor signs the Hyland Contributor License Agreement before a pull request can be merged. The CLA confirms you have the right to contribute the code and that Hyland can distribute it under the project's license.

## Before You Open a Pull Request

- Read the project's README. Labs projects are experimental, and some are not maintained.
- Open an issue first to confirm the change is wanted before you spend time on it.
- Keep pull requests small and focused on one change.
- Match the project's existing style, build, and test conventions.
- Confirm the change carries no third-party code that conflicts with the project's license.

## What Each Project Decides for Itself

Licensing, build tooling, test requirements, and review expectations live in each repository. Where a project's own CONTRIBUTING file differs from this one, that project's file wins.

## Code of Conduct

Be respectful and constructive in issues, pull requests, and discussions. Maintainers may close or lock anything that is not.
